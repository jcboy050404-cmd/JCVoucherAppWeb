# Plan: Dynamic, Admin-Editable MikroTik Device Limit (up to 100+)

Make the per-account MikroTik router limit **admin-editable via the cloud** (so you control it from the Admin screen without touching code) instead of the hardcoded `3`. You'll be able to set it to 100 (or any value 1–999).

## Default value decision
I'll keep the **fallback default at 3** (backward-compatible — won't accidentally unlock 100 routers for existing accounts the moment you deploy). You then **set it to 100 in the Admin screen** in one tap. If you'd rather the default itself be 100, that's a one-line change I'll flag.

---

## Changes

### 1. `lib/services/cloud_sync_service.dart`
- **Rename** `kMaxRoutersPerAccount` (line 221) → `kDefaultMaxRoutersPerAccount` (value stays `3`); it becomes the fallback when no cloud setting exists.
- **Add a cached getter** `static Future<int> getMaxRoutersPerAccount()` — returns a cached value, otherwise reads `getGlobalSettings()['max_routers_per_account']` (parse to int, fallback to `kDefaultMaxRoutersPerAccount`), caches it.
- **Add** `static void setMaxRoutersCache(int v)` — lets the Admin screen refresh the cache immediately after editing (no stale value).
- **`registerRouter` (line 243)** — replace the const with `final limit = await getMaxRoutersPerAccount();` then `if (existing.length >= limit)`. This is the **only** enforcement point, so this one edit makes the limit fully dynamic.
- `registerRouter` is only called once per session (verdict is cached in `TrialService._isDeviceAllowed`), so the extra settings fetch is negligible.

### 2. `lib/screens/admin_screen.dart`
- **New state field** `int _maxRouters = CloudSyncService.kDefaultMaxRoutersPerAccount;` + a `TextEditingController` for the numeric input.
- **`_loadGlobalSettings`** — also parse `settings['max_routers_per_account']` into `_maxRouters` and refresh the cache via `setMaxRoutersCache`.
- **New `_saveMaxRouters()` handler** — validates the input is 1–999, PATCHes `{'max_routers_per_account': v}` via `updateGlobalSettings`, refreshes cache, shows a success/revert toast (mirrors the existing `_togglePppoe` write pattern).
- **`_buildGlobalSettingsCard`** — add a new tile after "Unlock File Manager": a **numeric TextField + Save button** (or +/− stepper) labeled "Max MikroTik Devices per Account" with subtitle "Default 3 · current: N". Styled to match the existing tiles.
- **`_ManageDevicesDialog` (line 2122)** — `const max = CloudSyncService.kMaxRoutersPerAccount;` must change because the value is no longer a const. The dialog already loads routers async in `_loadRouters()`, so I'll fetch the limit there into a state field and display `used / max` dynamically.

### 3. `lib/services/trial_service.dart`
- **No change needed.** It calls `registerRouter`, which now enforces the dynamic limit. The `DeviceSlotResult` enum and `_isDeviceAllowed` logic stay as-is.
